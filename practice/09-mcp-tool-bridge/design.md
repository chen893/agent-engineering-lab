# 09 方案与验证选择

模式：能力校准。可以先读必要接口，写要点即可，不要求背协议或等批准。

## 用户先决定

1. 连接、工具发现、Agent 工具适配各由谁负责？哪些机制可以直接交给现有客户端，哪些需要自己写？
2. 两个服务器都有 search/get，模型看到的名字如何对应到远端？工具参数与结果经过哪些类型边界？
3. 服务正常返回 isError 与连接失败各应让调用者看到什么？创建失败和正常 dispose 时谁释放资源？
4. 自选几组输入/操作序列，写预期与观察位置，能区分“只是连上”“工具确实执行”“结果真的进入下一次模型请求”。测试代码可以交给 AI。
