## 收录口径

- 共 20 篇独立 URL；同一作者的一面、二面分别计篇，不拆分长帖凑数。
- 优先选择有具体问题的面试回顾，排除纯招聘、求职进度、明显重复内容和答案汇编。本批包括 Agent、AI 应用、涉及 Agent 的后端面经，以及 1 篇相邻的前端面经（M17）。
- 每篇已读取正文后整理为问题摘要；去掉口语重复、情绪表达和无关内容，长帖按主题压缩。这里不是原文存档或逐题逐字转录；完整措辞以原帖为准。
- 元数据区分发布时间和面试日期。原文未给出的代码、算法约束、版本和题目不补写；有歧义的术语和未经核实的前提另作说明。
- 面试过程为作者自述，真实性未独立核验。没有把原帖说法或平台解析当作正确答案，也没有把准备资料视作用户已掌握的能力。
- 收集来源偏向字节与该搜索词，不能据此声称覆盖 Agent 岗全部要求，或把主题出现次数当成真实面试频率。
