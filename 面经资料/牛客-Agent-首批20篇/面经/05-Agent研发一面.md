## 整理后的问题摘要

以下为自主归纳，合并口语化重复追问；不是全文转载，也不是标准答案。

1. 后端架构和业务状态机如何设计？从需求到上线的 AI 工作流如何运转，人工负责哪些环节？
2. 一次请求经过哪些层次和协议？SSE 与 WebSocket 如何选择，与 HTTP 是什么关系？
3. 使用过哪些 Agent 编排模式？如何理解 Multi-Agent 与 Sub-Agent，如何选型？
4. 长期记忆如何存储、检索和加载？是否需要向量库？超长上下文能否替代记忆分层和 RAG？
5. MySQL 事务特性、索引、联合索引匹配及失效情况如何理解？
6. Redis 持久化、过期删除和数据库缓存一致性如何设计？
7. select、poll、epoll 有什么区别？
8. 实现 LRU，说明高并发扩展方式及与 LFU 的区别。
