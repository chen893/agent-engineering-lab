## 整理后的问题摘要

以下为自主归纳，合并口语化重复追问；不是全文转载，也不是标准答案。

1. 如何拆分 Agent 核心模块，为什么选择这一开发方向？如何持续学习并使用 AI 编程工具？
2. Tool 如何划分职责、设计参数 schema 与错误码？
3. 记忆如何分层、存储、过期和去重？
4. ReAct 与 Plan-Execute 如何选择，如何避免无限循环或多 Agent 相互推诿？
5. 多 Agent 如何通信和共享状态？
6. RAG 如何切分文本、设置重叠并通过对比实验调参？召回不准时如何排查？
7. 混合检索与 rerank 如何设计？RAG 与微调如何选择或组合？
8. 如何降低 RAG 延迟与模型成本？
9. 如何分析 bad case 和幻觉？模型超时异常、监控与可观测性如何处理？
