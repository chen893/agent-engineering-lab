# 单次能力验证记录模板

复制到工作区 `learning-log/YYYY-MM-DD.md` 使用，不直接覆盖本模板。

- 日期：
- 问题编号及来源：
- 本次小目标：
- 实践模式：能力校准 / AI 辅助交付
- 开始前的预测或方案：
- 验收标准：正常行为、关键边界与失败条件
- 环境：仓库 URL、提交、相关文件；独立实验则注明
- 实际完成：
- 帮助程度：查阅资料、提示、AI 生成分别用于哪些步骤
- 验证证据：代码路径、运行命令、结果或测试输出
- 与预期不一致之处及原因：
- 当前状态：待验证 / 能解释 / 提示下完成 / 独立完成 / 能迁移
- 仍待验证的能力：
- 下次变式题：
- 复习日期：

不要仅以“看懂了”“跑通了”验收；说明哪些行为通过验证、哪些还没有。
