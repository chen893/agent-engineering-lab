# 问题池

本批将 20 篇笔记归并为 **78 个学习问题组**。同一组可包含多个相关追问，不代表 78 道原始独立面试题。来源链接说明对应主题在何处出现，不意味着每篇都问过该组全部细节。

## 使用方式

- P0：建议先做能力校准；P1：随后补齐；P2：按岗位或项目需要深入。优先级是结合当前目标作出的学习建议，不是招聘概率或难度排名。
- 状态依次可记为：待验证 → 能解释 → 提示下完成 → 独立完成 → 能迁移。使用 AI 完成交付要另记帮助程度，不自动升级为独立完成。
- 每次只挑 1～2 组，先定义验收标准。完成后按实际覆盖范围更新本表证据索引；有价值的变化再写学习日志，不要求逐题逐日留记录。
- 具体证据可用 [验证记录模板](验证记录模板.md) 记录；[实践入口](实践入口.md) 是初始候选，不按编号推进。当前进度以 [learning-state](../../learning-state.md) 及关联证据为准，短期安排见 [learning-plan](../../learning-plan.md)；部分表内状态尚未同步，不能直接据此认定未学习或已掌握。
- 已针对部分问题核对 pi 源码；其他仓库的研究深度以实际证据为准。后续源码关联仍须核实仓库、版本和关键文件，不能把练习建议当作仓库现状。
- M06 中模型比较和 Kafka 乱序来自另一家未具名公司附记；M17 是前端岗相邻能力参考。样本由一个搜索词筛选，不能据此推算市场题频。
