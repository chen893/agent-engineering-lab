# 知行 · Agent 学习工作台原型

当前进展、数据交互方案与接续入口见 [PROGRESS.md](PROGRESS.md)。

运行：`python3 -m http.server 4173 --directory dist`，打开 http://localhost:4173。

首页底部可切换三个布局（`?variant=A/B/C`）：回忆优先、今日路径、工程工作台。五个导航入口为今日、回忆练习、工程实践、能力证据、求职准备。

可操作流程：作答 → 提示/参考要点 → 自评与间隔安排；实践上下文复制；待审证据录入；岗位要求与案例表达草稿；JSON 导出。

所有操作仅在页面内存中，刷新重置。没有模型调用、编辑器连接、后台复习通知或自动验收。历史摘要来自 learning-state.md；题卡、队列与建议任务为演示，不改变已有实践任务与能力结论。

## 设计取舍

首页用一个主动作、复习队列、继续实践入口和最近证据组织视线；不以说明段落代替界面。暖白画布、衬线标题、陶土色操作按钮，支持窄屏布局与键盘焦点。

主动回忆优先展示作答区，参考要点在提交或主动求助后出现；提示与自评分别记录。1/3/7 天仅为初始演示规则。口头回忆不升级实现能力。工程验证、解释、个人贡献与迁移分列展示。VS Code 承担集中实现，网页承担学习组织与反馈。

依据：[Dunlosky 等（2013）学习技术综述](https://journals.sagepub.com/stoken/rbtfl/Z10jaVH/60XQM/full)。检索和间隔练习的研究证据不等于对本应用效果的验证。

## 待验证

用户选择或组合首页布局；是否愿意每天以回忆开始；实践与网页之间的手动交接是否顺畅。此原型由 AI 完整实现，不计为用户独立实现证据。
